# 任务清单

一个使用 HTML、CSS 和 JavaScript 编写的任务清单，适合个人日常学习和任务安排。

## 功能

- 首次使用可填写名字，显示“某某某的任务清单”，也可跳过使用默认标题；页面右上角可随时修改。
- 名字保存在当前设备的当前浏览器中，刷新或关闭页面后再次打开可恢复。
- 添加课程名称和任务内容，拒绝空白输入。
- 可选填写截止日期（DDL）备注，支持 `10月25日`、`910`、`下周五` 等任意文字，原样保存和显示。不解析日期，不提供时间、倒计时或提醒。
- 默认显示未完成任务，完成后从默认列表隐藏。
- 查看已完成或全部任务，支持取消完成。
- 同时按课程和完成状态筛选。
- 精确删除指定任务。
- 在浏览器本地保存任务及完成状态，刷新后恢复。
- 适配电脑和手机屏幕。

## 使用方法

GitHub Pages 发布成功后的网址：<https://beiguguguc.github.io/course-lab-todo/>。

首次打开时可填写名字并保存，或点击“暂不设置”；之后通过页面右上角的“设置名字”或“修改名字”更改。保存空名字可恢复默认标题“任务清单”。

输入课程名称和任务内容，按需填写 DDL，点击“添加任务”。DDL 没有固定格式，可以不填。勾选任务表示完成；切换到“已完成”可以回顾记录或取消完成。课程下拉框和状态按钮可以同时使用。

本地使用时，将 `index.html`、`styles.css` 和 `app.js` 放在同一文件夹，用浏览器打开 `index.html`。检查保存功能时，保持使用同一浏览器和同一打开地址。

## 数据保存在哪里

任务和名字保存在访问者当前浏览器、当前网站地址对应的 `localStorage` 中。此项目没有后端数据库或登录系统，不会把个人记录上传到 GitHub，也不会在不同使用者之间共享任务。

升级保留原来的任务存储项 `course-lab-todo-learning-v1`，名字独立保存在 `course-lab-todo-owner-name-v1` 中。加载页面不会重写旧任务；旧记录没有 `dueDate` 字段也能正常使用，任务 ID 和完成状态保持不变。

不同浏览器、设备或网站地址的记录不会自动同步；本地文件与 GitHub Pages 网站也不会自动共用记录。清除网站数据会删除已保存的任务，隐私浏览模式关闭后记录可能被清除。

## 文件结构

```text
index.html   页面结构与入口
styles.css   样式和响应式布局
app.js       任务操作、筛选与本地保存
README.md    项目说明
```

项目使用原生浏览器能力，不需要安装依赖或执行构建。

## GitHub Pages 发布方式

将上述文件放在仓库根目录。在仓库 `Settings → Pages` 中选择 `Deploy from a branch`，选择存放网页的分支（本项目使用 `main`）和 `/(root)`，保存并等待部署完成。

提交保存的是一版项目代码；部署把选定版本的网页文件发布为可访问的网站。
